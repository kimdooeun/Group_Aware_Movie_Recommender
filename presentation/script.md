# 전반부 발표 대본 (약 5분)

구성: 프로젝트 소개 → 데이터·EDA → MF. 소개와 EDA 슬라이드는 A가 만들고, 아래 문장은 A 슬라이드와 맞춰 확인이 필요하다. EDA 수치는 `ratings_train.csv` 기준으로 직접 계산한 값이다.

## 1. 프로젝트 소개 (약 50초)

안녕하세요, 저희는 여러 사람의 취향을 함께 고려하는 그룹 영화 추천 시스템을 만들었습니다.

친구 서너 명이 영화를 고를 때 각자 보고 싶은 게 다르죠. 기존 추천은 한 사람에게 맞추기 때문에 이런 상황에 잘 맞지 않습니다. 그래서 2명에서 5명까지의 사용자를 한 그룹으로 보고, 모두가 어느 정도 만족하는 영화를 추천하는 것이 목표입니다.

방법은 세 단계입니다. 먼저 개인별 영화 점수를 두 가지 방식으로 만듭니다. 하나는 협업 필터링인 Matrix Factorization, 다른 하나는 영화 줄거리와 키워드를 쓰는 TF-IDF 콘텐츠 기반입니다. 그다음 이 점수를 Average와 Least Misery 두 방식으로 합쳐 그룹 점수를 만듭니다. 저는 이 중 Matrix Factorization을 맡았습니다.

## 2. 데이터와 EDA (약 80초)

데이터는 MovieLens 1M입니다. 학습용 평점이 80만 193건, 평가용이 19만 9,984건이고, 사용자는 6,040명, 학습에 쓰인 영화는 3,680편입니다. 평가 데이터의 평점은 학습에 전혀 쓰지 않아 데이터 누출을 막았습니다.

분포를 보면 평점은 4점이 35%로 가장 많고 5점이 23%, 3점이 26%입니다. 1점과 2점은 합쳐도 16%여서 전체적으로 후한 편이고, 평균은 3.58점입니다.

중요한 점은 데이터가 매우 희소하다는 겁니다. 사용자 6,040명과 영화 3,680편을 곱한 표 중에서 실제로 채워진 칸은 3.6%뿐입니다. 사용자당 평점 수의 중앙값은 77건인데 최대는 1,851건으로 편차가 크고, 상위 20% 영화가 전체 평점의 65%를 차지합니다. 이렇게 비어 있는 칸을 어떻게 채울 것인가가 협업 필터링의 핵심 문제입니다.

## 3. Matrix Factorization (약 3분)

### 슬라이드 1: MF 아이디어 (약 40초)

Matrix Factorization은 이 비어 있는 평점표를 두 개의 작은 행렬의 곱으로 근사합니다. 사용자 행렬 P와 영화 행렬 Q인데, 둘 다 숨은 요인 50개로 이루어져 있습니다. 예를 들어 이 요인이 액션을 좋아하는 정도나 가벼운 영화를 선호하는 정도처럼 취향을 나타낸다고 생각하시면 됩니다.

예측 평점은 전체 평균에, 사용자가 원래 후하게 주는 정도, 영화가 원래 높게 평가받는 정도, 그리고 사용자 취향과 영화 성격이 맞는 정도인 내적을 더해서 계산합니다.

### 슬라이드 2: SGD 학습 (약 40초)

이 값들은 SGD로 학습했고, 라이브러리를 쓰지 않고 NumPy로 직접 구현했습니다. 평점 한 건을 뽑아 예측과의 오차를 구하고, 편향과 요인 벡터를 오차를 줄이는 방향으로 조금씩 갱신합니다. 정규화 항은 값이 너무 커지는 것을 막아 과적합을 줄여 줍니다. 80만 건을 섞어서 한 바퀴 돌면 1에폭이고, 20에폭을 반복했습니다.

### 슬라이드 3: 파라미터 튜닝 (약 45초)

학습률, 잠재요인 수 k, 정규화 세기를 바꿔 12개 조합을 비교했습니다. 이때 학습 데이터의 10%를 검증용으로 떼어 썼고, 평가 데이터는 튜닝에 쓰지 않았습니다.

결과는 학습률 0.01이 0.005보다 좋았습니다. 0.005는 20에폭 안에 수렴하지 못했습니다. 정규화는 0.05가 가장 좋았고 0.1은 오히려 성능이 떨어졌습니다. k는 50이 20보다 조금 나았습니다.

### 슬라이드 4: 결과 (약 45초)

가장 좋은 설정으로 전체 학습 데이터를 다시 학습해 평가 데이터에서 RMSE 0.855, MAE 0.672를 얻었습니다. 평점이 1점에서 5점이니, 평균적으로 0.67점 정도 틀린다는 뜻입니다.

비교 기준으로, 개인화 없이 모든 영화에 학습 평균 3.58점만 예측하면 RMSE가 1.118, MAE가 0.934입니다. MF는 여기서 RMSE를 23.5%, MAE를 28.0% 줄였습니다.

학습 RMSE는 0.74로 평가보다 낮아서 약한 과적합이 있지만, 오른쪽 그래프처럼 평가 오차는 마지막 에폭까지 계속 줄었습니다.

이 모델이 계산한 사용자별 영화 예상 평점을 D에게 넘기면, 그룹 점수 계산에 사용됩니다. 이어서 C가 콘텐츠 기반 추천을 설명하겠습니다.

# 예상 질문과 답변 (MF 관련)

**Q. 왜 Matrix Factorization을 골랐나요?**
평점표가 3.6%만 채워진 희소 데이터라 사용자-영화 간 직접 비교가 어렵습니다. MF는 소수의 숨은 요인으로 취향을 압축해서 보지 않은 영화의 점수까지 예측할 수 있고, 모든 사용자 × 영화 조합의 점수를 한 번에 만들 수 있어 그룹 점수 계산에 필요한 전체 후보 점수를 쉽게 얻습니다.

**Q. 편향(b_u, b_i)은 왜 넣었나요?**
후하게 주는 사용자와 박하게 주는 사용자, 원래 평이 좋은 영화와 나쁜 영화의 차이를 먼저 설명해 두면, 요인 벡터는 순수한 취향 차이에만 집중할 수 있습니다.

**Q. RMSE 0.855는 좋은 수치인가요?**
모든 영화에 학습 평균 3.58점을 예측하는 기준선은 RMSE 1.118, MAE 0.934입니다. MF는 RMSE를 23.5%, MAE를 28.0% 줄였습니다. 다른 논문의 수치와 직접 비교하지는 않았고, 같은 학습·평가 분할을 쓰는 팀 내 모델 비교 기준으로 봐 주세요.

**Q. 과적합은 어떻게 막았나요?**
L2 정규화(0.05)를 쓰고, 파라미터는 검증 세트로 골랐습니다. 학습 RMSE 0.74와 평가 RMSE 0.86 사이에 간격이 있어 과적합이 완전히 없다고는 할 수 없습니다.

**Q. 데이터 누출은 없었나요?**
평가 파일의 평점은 학습과 튜닝에 쓰지 않았습니다. 튜닝은 학습 데이터에서 분리한 10% 검증 세트로만 했고, 평가 데이터는 최종 성능 측정에만 사용했습니다.

**Q. 처음 보는 사용자나 영화는 어떻게 하나요?**
평가 데이터의 사용자와 영화는 모두 학습 데이터에 있었습니다. 코드는 모르는 사용자나 영화가 나오면 전체 평균과 아는 쪽의 편향만으로 예측하도록 처리해 두었습니다.

**Q. MF 점수와 TF-IDF 점수를 합칠 수 있나요?**
두 점수는 단위가 달라서 직접 비교하지 않습니다. MF는 1~5점 예상 평점이고 TF-IDF는 코사인 유사도입니다. 그룹 점수는 각 방식 안에서 따로 집계합니다.

**Q. 학습은 얼마나 걸렸나요?**
에폭당 약 11~30초이고, 최종 모델은 20에폭입니다. 순수 Python 루프라서 느리지만 numba가 있으면 자동으로 빨라집니다.
